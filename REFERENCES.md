pentest tools, guides and cheat sheets, reference docs, operating systems,
bug-bounty / VDP platforms, and external (non-vendored) SAST / DAST / SCA
indexes. The README is the usage guide; this file is reference material.

Each entry links to its upstream home. Catalog records for anything checked out
locally live as YAML in [`catalog/`](catalog/) and link into the
[`third-party-resources/`](third-party-resources/) submodule trees.
