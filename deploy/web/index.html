    Bug bounties & VDPs

    Marketplaces are aggregators you join to pick programs (HackerOne, Bugcrowd, Immunefi…). Programs are a single organization's own bounty or disclosure channel (MSRC, Apple, CERTs/NCSCs…). Contracts are the individual program listings hosted inside marketplaces — live on the Contracts tab, refreshed on a schedule. Search by company, asset, or vuln class; blank lists all.

      Playbook generator

      Live planner — a model (Workers AI, or your own OpenAI-compatible / OpenRouter endpoint) writes a tailored playbook per situation.

      Server default is pre-selected; OpenRouter options include the auto/free routers and free models when a key is configured.

      Account

      Sign in with Keycloak (realm openhat, client ohqs-api). Mint a client API token for metered calls. Session uses an HttpOnly cookie — no token in the URL bar.

      Sign up (self-serve)

      Creates a Keycloak user with realm role client. Separate from the invite-only engagement portal.

      Local debug: paste Keycloak access token

      AI tokens are internal / unlimited / audited. Realm role admin only. Never put them in README, CLI defaults, or www.
